# Visual Imagery Specification & Image Generation Roadmap

## 1. Executive Summary & Aesthetic Paradigm

This document governs the design system and visual generation pipeline for all card thumbnail images across Hanson-Tube (**Projects**, **Skills**, **Honors**, **Certifications**, **Community**, **Education**, and **Work Experience**).

### Aesthetic Core Principles (Elevating `origin/main` Standards)

1. **Photorealism & Tactile Realism**: Real physical materials (weathered wood, textured paper, brushed aluminum, glass, brass, silicone circuits, natural fabrics). High-key studio stills and natural architectural lighting.
2. **Lens Craft & Optical Physics**: Cinematic shallow depth of field (DoF), authentic bokeh, f/1.4 - f/2.8 lens blur, macro detail, tilt-shift focus, natural atmospheric falloff.
3. **No-People-First Rule**: Avoid human faces/figures wherever possible; focus on physical objects, workstations, tactile tools, architectural environments, knolling layouts, and isometric 3D clay compositions. When human presence is strictly required for narrative context (e.g. hands placing sticky notes, collaborative team flat-lay, military uniform), use hyper-photorealistic documentary realism.
4. **Selective Brand Color Accents**: Thoughtfully integrate subtle Hanson-Tube crimson red (`#DC2626`) and deep purple/indigo accents (e.g. subtle LED indicator, book spine, ambient rim light, stationery accent, UI element) where organically appropriate—avoiding repetitive dark-room cyberpunk saturation.
5. **No Monolithic Battlestations**: Avoid repetitive dark-room streamer setups with curved monitors. Every domain must reflect its authentic physical craft (aviation cockpit, mailroom lockers, camera knolling, Scrabble tiles, physical Kanban board, circuit motherboard).

## 2. Aesthetic Comparison: `origin/main` vs. Target Generation Paradigm

| Dimension         | `origin/main` (Handpicked Baseline)                                                                  | Target Generation Paradigm                                                                                                              |
| :---------------- | :--------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- |
| **Visual Tone**   | Natural daylight, authentic lifestyle/documentary, warm organic textures, minimalist 3D clay/pastel. | Elevated 8k photorealism, tactile textures, rich lens blur (f/1.8 bokeh), clean natural lighting with subtle Hanson red/purple accents. |
| **Subject Focus** | Physical metaphors (PO boxes, Scrabble tiles, analog cockpit, dress uniform, sticky Kanban).         | Domain-authentic physical tools, clean minimalist flat-lays, macro hardware, refined 3D isometric models.                               |
| **Human Element** | Natural candid team/mentor presence, hands.                                                          | Zero people by default; hyper-photorealistic hands/props only when structurally necessary.                                              |
| **Composition**   | Warm studio still life, architectural depth, macro focus.                                            | Golden hour/studio lighting, tactile surfaces, deliberate focal falloff, 16:9 cinematic aspect ratio.                                   |

## 4. Execution Workflow

1. Ingest/generate each 16:9 source asset into `media/<category>/<filename>.jpg` (non-deployed local raw source repository).
2. Execute `pnpm run assets:convert` (`scripts/convert-assets.mjs`) to batch-convert and optimize all assets to high-compression WebP in `public/assets/generated/<category>/<filename>.webp`.
3. Verify visual quality, aspect ratio, and theme compatibility across light and dark modes.
