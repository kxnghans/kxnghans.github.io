### Architectural & Usability Highlights

1. **Neumorphic Token Fidelity**: In both Light and Dark themes, cards present calibrated dual-layer shadows (`UI_SURFACES.cardInteractive`) with contrast ratio exceeding WCAG AA standards.
2. **Search Indexing & Red Highlighting**: The client-side search engine segments terms with high visibility red badges (`rounded-xs bg-red-500/15 text-red-600 dark:bg-red-500/25 dark:text-red-400`). Recommended topics show categorized suggestions when query is empty.
3. **Reactive Impact Engine**: The Executive Value Dashboard computes dynamic aggregations for filtered savings, project counts, and sector breakdowns without page reloads.
4. **Responsive Integrity**: Breakpoints at 1440px (Desktop), 768px (Tablet), and 375px (Mobile) scale layout elements without horizontal scrollbar spill or element truncation.
